# Работа с ИИ

**Инструмент:** Codex. **Модель:** GPT-6 Astra.

Я использовала ИИ как помощника при поэтапной разработке: для разбора требований, проверки кода и объяснения незнакомых деталей. Самостоятельно собирала приложение и обработчики по обсуждённому плану, присылала изменения на проверку. По отдельным запросам ассистент дописывал модель платежа, схемы, расчёт графика рассрочки, создавал тесты и README. Конфигурации Docker и CI также готовились с его помощью.

## Примеры запросов

1. «Допиши вторую функцию и проверь первую. Объясни свои решения». Контекст: файл `services.py` с расчётом скидки и начатой функцией рассрочки. Разобрали целочисленное деление через `divmod` и распределение остатка по первым платежам.
2. «Проверь routes, предложи правки». Контекст: текущий обработчик создания платежа. При проверке разбирались сохранение данных, различие между `None` и пустым списком, повторные запросы и конфликт уникального ключа.
3. «Напиши тесты и расскажи о них подробно (много тестов не надо, только самое важное)». Контекст: готовые эндпоинты создания и получения платежа. Затем я отдельно уточняла работу фикстур, параметризации и моделирования конфликта ключей, чтобы понимать проверки.

## Неудачный совет и исправление

Ассистент предложил сохранить зависимости командой `python -m pip freeze > requirements.txt`. В используемом PowerShell файл получился в UTF-16. Во время проверки ассистент прочитал начало файла и обнаружил кодировку; после этого зависимости были пересохранены в UTF-8 через `Out-File -Encoding utf8`. Таким образом, первоначальная рекомендация не учла особенности моего окружения.

## Проверка результата

Код проверялся Ruff и pytest, миграции - на пустой временной базе. Дополнительно проверены сборка и запуск Docker, тесты внутри контейнера и запуск GitHub Actions. Тесты проверяют суммы и данные в базе, а не только HTTP-коды. Проверка конфликта идемпотентности моделирует пропуск записи при первом поиске и вызывает реальное нарушение уникальности; полноценное нагрузочное тестирование параллельных запросов не проводилось.
